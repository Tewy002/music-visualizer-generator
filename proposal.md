## Description
This program will create a visualizer from images and audio. It will help me make music videos that are consistant and appealing.

## Features
- Audio wave
	- The main visual feature. It will display a set of bars, which will rise/fall in sync with the audio presented. The frequencies of the audio are also aligned with the bars, with the left side being bass and right being treble.
- Image display
	- You can upload 2 images, one for the album art and one for the background. They will then be displayed in the main window. There can be just a background/album art or both.
- Text display
	- You can input a title, artist, album, and genre and it will display them in the window. There can be missing values too.
- File upload/export
    - The program will ask you to upload an background image, album image, audio file. You can save the video as an .mp4 at 1080p
