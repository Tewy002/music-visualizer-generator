## Description
This is my final project for Programming for Digital Arts, a music visualizer generator coded in Python! It's pretty straight forward in terms of what it does, just drop some music, a background image, and album art and it will create a music video that looks somewhat appealing.

To use the program, make sure to have all the libraries in `requirements.txt` installed. Then simply run `project.py`, along with arguments of `file.mp3 background.png album.png`. Background and album images can be replaced with `none` if they don't apply.
Space = Pause/Unpause
Enter = Start/Stop
Esc = Exit

I made this program because of my love for music and making music. I thought it would be super cool if instead of uploading just a static cover art, I can have some cool visualizations that sync up with the music. Of course I was inspired by the many other audio visualizer generators out there, but I wanted something that suited my vision: a nice background with cover art and descriptions on the side, and of course, a bar visualizer that I legit couldn't find on that looked like this.

Of course this program isn't perfect and very messy, but in the end it produced a result that I'm happy with, and can definitely start using if I want to make music videos.
